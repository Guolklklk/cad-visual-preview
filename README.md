## 这是什么

一张住宅平面布置图的**彩色表现稿（彩平图）**，用于向客户/评审者展示空间关系、
地面材质与配色方案。采用低饱和暖灰色调。

- **户型**：117㎡ 三居（练习题／教学用图纸，非真实客户项目）
- **内容**：房间分隔、户型面积、地面材质（木地板／瓷砖／石材）、家具布置、柔和阴影
- **生成方式**：由 CAD 矢量数据程序化渲染（非 AI 图像生成，图形位置与原始图纸一致）
